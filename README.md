# Metaplanet mNAV 電卓

メタプラネット(東証 3350)の **mNAV倍率** と **EV mNAV倍率** を計算する単一ファイルのWebツールです。
ビットコイン価格は1分ごとに自動取得し、株価を入力するだけで両方の倍率が更新されます。

## 計算式

```
mNAV    = (株価 × 発行済株式数) ÷ (BTC価格 × BTC保有量)
EV mNAV = (時価総額 + 有利子負債 + 優先株残高) ÷ (BTC価格 × BTC保有量)
```

いずれも現金など他の貸借対照表項目は考慮しない簡易指標です。
[analytics.metaplanet.jp](https://analytics.metaplanet.jp/) が表示する `EV mNAV` と同じ定義です。

## 価格の自動取得

| 系統 | 提供元 | 備考 |
|---|---|---|
| 主系 | [CoinGecko](https://www.coingecko.com/) | APIキー不要・CORS許可あり |
| 予備 | [Kraken](https://www.kraken.com/) | 主系が失敗したときのみ使用 |

- 60秒ごとに取得します。
- 取得値が妥当な範囲外なら破棄して予備系にフォールバックします。
- 価格欄を手で編集すると自動更新が停止し、「自動更新に戻す」で復帰します。
- タブが非表示の間はAPIを呼ばず、復帰時に即座に最新化します。

株価(3350)は、無償かつCORS対応のAPIが見当たらないため手動入力です。

## 前提条件の更新

BTC保有量・発行済株式数・有利子負債・優先株残高は開示値をハードコードしています。
画面の「前提条件を編集」から変更できます。

メタプラネットが新たにビットコインを購入したら、**BTC保有量**と**発行済株式数**を更新してください。

## 使い方

`index.html` を開くだけです。ビルド不要・依存パッケージなしの単一ファイルです。

## 免責

参考値を計算するツールであり、投資助言ではありません。監査済み財務諸表や公式評価を表すものではありません。
