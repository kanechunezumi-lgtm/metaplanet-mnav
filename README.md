# Metaplanet mNAV 電卓

メタプラネット(東証 3350)の **mNAV倍率** と **EV mNAV倍率** を計算する単一ファイルのWebツールです。
ビットコイン価格・株価・前提条件(株数・BTC保有量・負債・優先株)はすべて自動取得され、倍率が自動計算されます。

## 計算式

```
mNAV    = (株価 × 発行済株式数) ÷ (BTC価格 × BTC保有量)
EV mNAV = (時価総額 + 有利子負債 + 優先株残高) ÷ (BTC価格 × BTC保有量)
```

いずれも現金など他の貸借対照表項目は考慮しない簡易指標です。
[analytics.metaplanet.jp](https://analytics.metaplanet.jp/) が表示する `EV mNAV` と同じ定義です。

## 価格の自動取得

| 系統 | 提供元 | 取得内容 | 頻度 |
|---|---|---|---|
| BTC価格・主系 | [CoinGecko](https://www.coingecko.com/) | BTC/JPY を直接取得 | 60秒 |
| BTC価格・予備 | [Kraken](https://www.kraken.com/) + [ExchangeRate-API](https://www.exchangerate-api.com/) | BTC/USD × USD/JPY | 60秒 |
| 株価 | strategytracker | 3350.T の円建て価格 | 60秒 |
| 前提条件 | strategytracker | 株数・BTC保有量・負債・優先株 | 1日1回 + 手動 |

いずれもAPIキー不要・CORS許可ありです。

予備系が BTC/JPY を直接引かないのは、Kraken の BTC/JPY 板の24時間出来高が
0.03 BTC 程度しかなく、最終約定値が実勢から 0.2〜0.5% ずれるためです。
流動性のある BTC/USD から導出すると、主系との差は 0.02〜0.04% に収まります。

- 60秒ごとに取得します。
- 取得値が妥当な範囲外なら破棄して予備系にフォールバックします。
- 価格欄を手で編集すると自動更新が停止し、「自動更新に戻す」で復帰します。
- タブが非表示の間はAPIを呼ばず、復帰時に即座に最新化します。

## 前提条件

株数・BTC保有量・有利子負債・優先株残高は自動取得します。1日1回、
または画面の「更新」を押したときに取りに行きます。買い増しの開示があった日は
「更新」を押せば即座に反映されます。

画面の「前提条件を編集」から手で上書きもできます。上書きした欄だけ自動取得が
止まり、他の欄は自動のまま動きます。「すべて自動取得値に戻す」で復帰します。

取得できないときはキャッシュ、それも無ければファイル内の固定値
(2026-08-31開示時点)まで後退し、その旨を画面に赤く表示します。
黙って古い数字を出すことはありません。

## 本家サイトとの突き合わせ

analytics.metaplanet.jp が表示するのは **EV mNAV だけ**で、素の mNAV は載っていません。
本家と比べるときは、必ずこのツールの **EV mNAV** 側を見てください。時価総額ベースの mNAV と比べると
0.2 前後ずれて見えますが、これは指標の定義が違うだけです。

なお mNAV は分子・分母とも同じ通貨建ての比率なので、**為替レートをどう置いても値は変わりません**。
本家が購入履歴に併記している `1 USD = xxx JPY` は取得単価の換算用で、倍率には影響しません。

### 本家と 0.01 ずれることがある

本家のダッシュボードはタイルごとに少しずつ違う入力で計算されており、
表示同士が内部で一致していません。2026-09-09、株価 ¥251 の同時点で
本家の3つの表示から発行済株式数を逆算すると、どれも違う値になります。

| 本家の表示 | そこから逆算した株数 |
|---|---|
| 時価総額 ¥3,375億 | 1,344,621,513 |
| 1株あたりNAV ¥387.70 | 1,346,081,763 |
| 企業価値(EV) ¥4,333億 | 1,348,884,971 |

同じデータ源が配っている開示値は 1,345,340,624 株で、この3つのどれとも
一致しません。幅は約430万株(0.32%)あります。

このツールは1つのスナップショットから全部を計算するので内部矛盾はありませんが、
その代わり本家のどのタイルとも小数第2位まで揃うとは限りません。切り捨て表示の
境目に乗ると 0.01 の差になります(この日は本家 0.83 に対し 0.8286 → 0.82)。

貸借対照表に未知の項目があるわけではありません。

## 表示の丸め

倍率は本家 analytics.metaplanet.jp の表示に合わせて **切り捨て** で2桁表示します。
四捨五入すると本家と 0.01 ずれる場合があるためです(例: 0.8664 → 本家 0.86 / 四捨五入 0.87)。
プレミアム・ディスカウントの % は切り捨て前の値から計算しています。

## 使い方

公開URL: https://kanechunezumi-lgtm.github.io/metaplanet-mnav/

スマホのブラウザで開き「ホーム画面に追加」すると、アドレスバーなしのスタンドアロン表示で起動します。

ローカルで使う場合は `index.html` を開くだけです。ビルド不要・依存パッケージなしで動きます。
